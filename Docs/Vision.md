Construir un motor de negociación (Matching Engine) institucional-grade, comenzando por un núcleo puramente lógico, determinista y verificable. A largo plazo, el proyecto evolucionará hacia una plataforma B2B de infraestructura financiera que ofrezca integridad transaccional, latencia predecible y observabilidad, sirviendo como base licenciable para fintechs o brokers que necesiten reemplazar sistemas legados o cajas negras in-house.
